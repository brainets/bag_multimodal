# Functional and Structural Brain Age Gaps as Complementary Predictive Markers for Cognitive Performance

Code implemented for the paper by *<b>Crocetta, A., Morandini, M.</b>, Bittner, N., Caspers, S., Cauda, F., Brovelli, A. & Gilson, M.* (2026).
Functional and Structural Brain Age Gaps as Complementary Predictive Markers for Cognitive Performance. bioRxiv preprint: [https://www.biorxiv.org/content/10.64898/2026.10.20.760445v1](https://www.biorxiv.org/content/10.64898/2026.10.20.760445v1)

## Contents
- ``source``
    - ``bag_pipeline.py``: functions for predicting age from input features with cross-validation.
- ``notebooks``
    - ``BAG.ipynb``: create example data and implement brain age prediction with BAG and AgeML pipelines.
- ``data``
    - ``example_data.csv``: synthetic data randomly generated used as example for the age predictions.
- ``results``
    - ``ageml``: folder containing age predictions form the AgeML toolbox for the example data.
    - ``bag``: folder containing age predictions from BAG pipeline for the example data.
