# Functional and Structural Brain Age Gaps as Complementary Predictive Markers for Cognitive Performance

Code implemented for the paper by *<b>Crocetta, A., Morandini, M.</b>, Bittner, N., Caspers, S., Cauda, F., Brovelli, A. & Gilson, M.* (2026).
Functional and Structural Brain Age Gaps as Complementary Predictive Markers for Cognitive Performance. bioRxiv preprint: [..](..)

## Contents
- ``source``
    - ``bag_pipeline.py``: functions for predicting age from input features with cross-validation.
- ``notebooks``
    - ``BAG.ipynb``: create example data and implement brain age prediction with BAG and AgeML pipelines.
- ``data``
    - ``example_data.csv``: synthetic data used as example data for the age predictions.
- ``results``
    - ``ageml``: folder containing age predictions form the AgeML toolbox.
    - ``bag``: folder containing age predictions from BAG pipeline.
